# Blok Ustası

Çocuklar için 3D blok yapma oyunu. **Oyna ya da Android'e indir:** https://mustafatanirli.github.io/blokustasi/

Bu depo yalnızca yayımlanan oyunu içerir (derlenmiş sayfa ve APK). 3D motor: three.js (MIT); yazı tipleri: Lilita One ve Nunito (SIL Open Font License, metinleri `oyna/fonts/` içinde).
